# 嵌入层（Embedding Layer）

**解决什么问题**：把词变成数字向量的第一步，模型内部只认数字。

模型内部把每个 token 映射成高维向量的那一层，是向量检索技术的源头。

**为什么需要知道**：它连接了「原理层」和「应用层」——你理解的 embedding 概念，和这里的实现是同一个东西。
