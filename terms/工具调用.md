# 工具调用（Tool Calling / Function Calling）

**解决什么问题**：模型自己决定「我要查一下数据库」，然后真的去调那个程序。

模型输出一个结构化的调用意图，由你的程序执行后把结果喂回去。

模型本身不执行任何东西，它只是输出「要调哪个函数、传什么参数」。

**为什么需要知道**：这是 Agent 能「真的做事」而不是「只是说要做」的分界线。没有它，模型只能空谈。
