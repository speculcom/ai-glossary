# GPU（Graphics Processing Unit）

**解决什么问题**：真正做矩阵运算的芯片。跑大模型靠它，CPU 很慢。

擅长大规模并行计算的处理器，最初为图形渲染设计，现在是大模型训练与推理的主力。

**别名**：显卡、图形处理器

**为什么需要知道**：决定你「能不能跑、跑多快」。同一张卡，显存大小比算力型号更卡脖子。
